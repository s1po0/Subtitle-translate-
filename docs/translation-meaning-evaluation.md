# Evaluating subtitle meaning

A change to text processing should not be called a meaning improvement just because it preserves markers or achieves a higher overlap score. Evaluate complete English-to-Sorani dialogue with native speakers, including idioms, negation, pronouns, names and cases where the same phrase has different meanings. Keep held-out examples separate from any rules or glossary built from examples. Record omissions and mistranslations as well as fluency, and compare on the same inputs. For subtitle context experiments also check cue alignment, timestamps and formatting.

## Exploratory baseline

The [CORDI machine translation data](https://github.com/sinaahmadi/CORDI/tree/main/MT) contains 300 English dialogue sentences with a standard Central Kurdish reference and several dialectal references. Using the upstream files at commit `05f053849214e9703726d69c94b5d669440a30eb`, we compared `MT/gold-standard/ckb.txt` with the archived `MT/translations/en_translated_Google.txt` and `en_translated.txt` (the latter is the NLLB output described by the project). The simple character n-gram F1 script in this repository yielded 32.51 and 25.17 out of 100 respectively. These numbers are not percentages of correct translations, are not standard chrF, do not evaluate meaning, and do not prove which engine is better. CORDI's test set is small, is not a Badini test set, and uses one reference; valid alternative wording can score poorly. The outputs are historical, not a test of today's Google or of this app's exact transport and context settings.

The reference and outputs were fetched only for local analysis and are not bundled. CORDI describes its resources as CC BY-SA 4.0; check upstream terms and provenance before distributing or adapting data. The [KurdishLexicography](https://github.com/sinaahmadi/KurdishLexicography) dictionary and [InterdialectCorpus](https://github.com/KurdishBLARK/InterdialectCorpus) have non-commercial/share-alike terms; neither is included here. A lexicon alone cannot resolve context, and injecting automatic substitutions into output risks changing meaning.

To repeat the lexical diagnostic using separately obtained aligned UTF-8 files, run `python3 scripts/compare-kurdish-translations.py reference.txt hypothesis.txt`. Each file must have exactly one corresponding nonempty sentence per line. NFC normalization and whitespace removal are applied; the score averages corpus-level character n-gram F1 for lengths 1–6. For actual quality decisions, complement this diagnostic with blinded human review and real subtitle formatting and timing tests. Live Google requests could not be performed from this sandbox because outbound access to Google is blocked.
